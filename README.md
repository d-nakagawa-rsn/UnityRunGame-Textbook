# Unity無限ランナー教材

Unityで3D無限ランナーを制作しながら、複数の機能やクラスを組み合わせて一本のゲームを完成させる方法を学ぶ教材です。

## 対象読者

Unityの基本操作とC#の基礎を理解しているものの、一本のゲームを設計・実装し、完成させた経験が少ない人を対象とします。

## 読者が抱えている課題

Unityの個別機能は理解していても、複数の機能やクラスをどのように組み合わせ、一本のゲームとして完成させればよいのか分からないという課題を扱います。

## 読了後に得られること

3D無限ランナーを題材として、次の要素を連携させ、一本のゲームとして組み立てる方法を理解できます。

* プレイヤー
* ステージ
* ゲーム進行
* UI
* サウンド
* 演出

## 本教材で扱うこと

* 無限ランナーの設計
* ゲームの実装手順
* 各クラスの役割
* 複数の機能を連携させる考え方
* 実装方法を選択した理由

## 本教材で扱わないこと

* Unity Editorの初歩的な操作説明
* C#文法の基礎
* 3Dモデルの制作
* BGMや効果音の制作
* 課金や広告の実装
* アプリストアへの公開手順

## 収録物

本教材の収録物はPDF形式の技術書です。

Unityプロジェクト本体は付属しません。

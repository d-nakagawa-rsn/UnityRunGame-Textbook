# はじめに

本書をお手に取っていただきありがとうございます。チュートリアル通りに小さなゲームは作れたけれど、いざ自分のオリジナルゲームを作ろうとすると、何から手を付けていいか分からない。機能の組み合わせ方が分からず、コードがぐちゃぐちゃになってしまう……。  
本書は、そんな壁にぶつかっている方のための本です。

## 1. 本書について

本書は、Unityで制作した3D無限ランゲームを題材として、一本のゲームがどのように設計・実装され、完成していくのかを解説する本です。Unityの基礎知識を一つずつ体系立てて学ぶ入門書ではありません。また、記載された操作を順番に再現し、読者が同じゲームを完成させることを目的としたハンズオン形式の教材でもありません。

Unityには、プレイヤーの制御、入力、ステージ生成、UI、サウンド、演出など、ゲームを構成するためのさまざまな機能があります。しかし、それぞれの機能を個別に理解していても、それらをどのように組み合わせ、一本のゲームとして成立させればよいのかは分かりにくいものです。

完成したコードを提示するだけでなく、なぜその構成を採用したのか、実装時に何を考えたのかについても取り上げます。本書で紹介する設計や実装を、そのまま別のゲームへ適用できるとは限りませんが、自分のゲームを組み立てる際の判断材料として役立ててもらうことを目的としています。

## 2. 本書で取り上げるゲーム

本書では、Unityで制作した3D無限ランゲームを取り上げます。具体的には以下の要素を含みます。

- ゲーム開始からゲームオーバー、リザルトまでの進行
- プレイヤーの自動走行
- 入力に応じた方向転換
- 床タイルの動的な生成
- BGMと効果音の再生
- ゲームを彩る演出
- ゲーム進行に応じた難易度の変化
- WebGL形式でのビルド
- itch.ioを利用したゲームの公開

## 3. 想定している読者

本書では、次のような読者を想定しています。

- Unity Editorの基本操作を理解している
- GameObject、Component、Prefab、Sceneなどの意味を理解している
- C#のクラス、変数、メソッド、条件分岐、繰り返し処理などを読める
- 小規模なサンプルやチュートリアルを試した経験がある
- Unityの個別機能はある程度分かるが、一本のゲームを完成させた経験が少ない
- 一本のゲームを設計から完成・公開まで組み立てる考え方を学びたい

## 4. 本書で扱わないこと
本書は、UnityやC#を初めて学ぶ人を対象とした入門書ではありません。そのため、次の内容については詳しく解説しません。

- Unity Editorの基本操作
- GameObject、Component、Prefabなどの基本概念
- C#の基本文法
- Unity Asset Storeの基本的な利用方法
- Photoshopを使った画像制作
- Blenderを使った3Dモデル制作
- BGMや効果音そのものの制作
- App StoreやGoogle Playなどへの申請手順

また、itch.ioのアカウント作成やプロフィール設定など、一般的なWebサービスの登録手順についても詳しくは扱いません。

## 5. 開発環境

本書で取り上げるゲームは、以下の環境で制作しています。Unityや使用するパッケージのバージョンが異なる場合、本書に掲載した画面やAPIなどと差異が生じることがあります。

- Unity 6000.3
- Universal Render Pipeline（URP）
- Input System パッケージ
- C#

## 6. 本書の読み方

本書では、3D無限ランゲームの実装を、ゲームの構成要素ごとに順番に解説します。読者が本書で取り上げるゲームと同じものを最初から作成することは前提としていません。掲載したコードや図を通して、各クラスの役割、機能同士のつながり、実装上の判断を解説していきます。

## 7. 読み終えたときに得られるもの

本書を読み終えることで、プレイヤー、ステージ、ゲーム進行、UI、サウンド、演出といった複数の要素が、一本のゲームの中でどのように役割分担し、連携しているのかを理解できます。個別の機能やAPIの知識だけでは得にくい、ゲーム全体を見渡して設計・実装するための基礎体力を身につけることが、本書の目標です。また、無限ランゲームの完成形を単に模倣するのではなく、本書で紹介する考え方を、自分が制作する別のゲームへ応用できるようになることを目指します。

## 8. 完成品
本書で取り上げるゲームは、itch.ioで実際にプレイできます。本書を読み進める前に、一度ゲームをプレイしておくと、これから解説する機能や実装の目的をイメージしやすくなります。
